Crypto News & Sentiment Impact Analyzer

Semester Project - Implementation & User Manual

1. Project Overview

The Crypto Sentiment Analyzer is a software tool designed to help traders and investors understand market psychology. It leverages advanced Natural Language Processing (NLP) techniques to analyze financial news and user-provided text, determining whether the sentiment is Positive, Negative, or Neutral.

This project fulfills the requirements for both Information Retrieval (IR) and Software Engineering (SE) courses by combining custom IR algorithms (TF-IDF Ranking) with a robust SE architecture (Layered Pattern, Factory Design Pattern).

2. Installation Guide

Follow these steps to set up the project on your local machine.

1 Prerequisites

Ensure you have Python 3.10+ installed. You can check by running:

python --version
2 Unzip & Navigate

Extract the project folder and open your terminal/command prompt inside it:

cd crypto_analyzer
3 Install Dependencies

Install all required libraries using the provided requirements file:

pip install -r requirements.txt
4 Initial Setup (Important)

Run the setup script to download necessary NLTK dictionaries (Stopwords, Lexicons):

python setup.py
5 API Key Configuration (Optional)

To use real-time news fetching, rename .env.example to .env and add your CryptoPanic API key. If skipped, the app runs in Mock Mode automatically.

3. User Manual: How to Use

Launch the application by running the following command:

streamlit run src/dashboard/app.py

Mode A: Real-Time Market Analysis

  1. Go to the "📡 Real-Time Market" tab.
  2. Select a cryptocurrency (e.g., Bitcoin, Ethereum) from the sidebar.
  3. Choose a Sentiment Model (FinBERT is recommended for finance).
  4. Click "Fetch Market Data". The app will:
    • Fetch the latest news headlines.
    • Fetch recent price data (OHLCV) from Yahoo Finance.
    • Calculate sentiment scores for every headline.
  5. Analyze the Chart: Scroll down to see the "Price vs. Sentiment" chart. Look for correlations (e.g., do green sentiment bars precede a price jump?).
  6. Search: Use the "Semantic Search Engine" box to filter news (e.g., type "ETF" to find ETF-related news).

Mode B: Manual Text Analysis (SRS Requirement)

  1. Go to the "✍️ Manual Analyzer" tab.
  2. Type any sentence into the text box (e.g., "The market is crashing because of new regulations!").
  3. Click "Analyze Text".
  4. The system will display:
    • Sentiment Label: Positive/Negative/Neutral.
    • Confidence Score: A value between -1.0 and 1.0.

4. System Architecture & Design

This project adheres to strict Software Engineering principles:

  • Layered Architecture: Separation of Presentation (Dashboard), Business Logic (IR Engine), and Data Access (News/Price Fetchers).
  • Factory Pattern: Used in sentiment.py to dynamically switch between models (VADER vs. FinBERT).
  • Singleton Pattern: Used in config.py to manage configuration globally.
  • IR Implementation: Custom TF-IDF Ranker and Text Preprocessing pipeline (Tokenization, Lemmatization).

5. Troubleshooting

Issue: "StreamlitInvalidWidthError" or app crash.
Fix: Ensure you are using the latest code provided. We fixed this by using use_container_width=True instead of width=None.
Issue: FinBERT score is always 0.
Fix: This usually means PyTorch is not installed correctly. Run pip install torch. The app will fallback to VADER if FinBERT fails.
