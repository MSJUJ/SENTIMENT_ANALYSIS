Important Notes  Code Freeze: All coding must cease by the submission deadline if you are submitting the link to a GitHub repository. No late commits will be accepted in the final review.  Collaboration: All team members are responsible for the entire codebase and must be able to explain any part of the implementation during the viva or final demo.  Start Early: Implementation always takes longer than anticipated. Break the project down into small, measurable tasks (e.g., using a Kanban board) and commit code frequently.  No New Features: Focus on implementing the features already specified in your SRS, not adding new ones.
